Mixt Web OS 1.0 — a whole desktop computer inside a web page.

Mixt Web OS boots a window manager, a panel, a virtual filesystem, a
terminal, a file manager, a software store and a web browser — all
client-side, no server required.

Keyboard shortcuts
  Super                open the menu
  Alt+Tab              switch windows
  Ctrl+Alt+T           open a terminal
  Ctrl+Alt+Left/Right  switch workspaces
  Super+D              show the desktop
  Alt+F2               run a command

The whole filesystem lives in your browser's localStorage at
/home/mixt/ — poke around, nothing breaks.
