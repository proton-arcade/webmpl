# Welcome to Mixt Web OS

You are looking at a complete desktop, running entirely in your browser.

## Things to try
1. **Menu ▸ Web Browser** — browse the built-in *MixtNet* internet, or real websites.
2. **Menu ▸ Terminal** — type `neofetch`, `ls`, `help`.
3. **Menu ▸ Software Manager** — install extra apps like Photo Studio.
4. Drag windows, snap them to screen edges, switch workspaces in the panel.
5. Right-click the desktop to change the background.

Everything you create is saved in your browser and survives a reboot.
